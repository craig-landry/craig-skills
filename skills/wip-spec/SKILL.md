# Technical Specification Generator

Take everything we have talked about and that you know about what we're working on and write a detailed and comprehensive software development implementation plan. Write this to the file `wip.md`. If it already exists, overwrite it.

The audience you are writing for is another software developer AI agent. That agent can be expected to be excellent at writing code. You don't need to spell out every single function, field type, etc. You do need to lay out the design and get into some detail though. One especially important factor is the overall design and architecture. You are a "smarter" agent and need to know how this all fits together, that things aren't missed, and the work takes the entire application into consideration for the scope of the change.
